# Tech Stack: HEMA Training Tool

## Core
- **Language:** Rust (2024 edition)
- **Game Engine:** Bevy 0.18.0
- **UI Framework:** Bevy UI Widgets 0.18.0
- **Utility:** Rand 0.9.2

## Build & Test
- **Build Tool:** Cargo
- **Test Framework:** Rust standard library (`cargo test`)
- **Linting:** Clippy (`cargo clippy`)
